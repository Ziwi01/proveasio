# Other software

## Command-line tools

- [eza](https://github.com/eza-community/eza) - modern `ls` with icons, colors and Git status (aliased as `ls` and `ll`)
- [bat](https://github.com/sharkdp/bat) - `cat` with syntax highlighting and line numbers (aliased as `cat`, also used as the man pager)
- [ripgrep](https://github.com/BurntSushi/ripgrep) (`rg`) - much faster grep, also used inside Neovim
- [fd](https://github.com/sharkdp/fd) - faster, simpler `find`
- [fzf](https://github.com/junegunn/fzf) - fuzzy finder behind history search, file search and many aliases
- [zoxide](https://github.com/ajeetdsouza/zoxide) (`z`) - jump to directories you visited before
- [pay-respects](https://github.com/iffse/pay-respects) (`f`) - corrects the previous command
- [jq](https://jqlang.org/) and [yq](https://mikefarah.gitbook.io/yq/) - JSON and YAML processors
- [fx](https://github.com/antonmedv/fx) - interactive JSON viewer
- [curlie](https://github.com/rs/curlie) - `curl` with HTTPie-style output
- [ShellCheck](https://github.com/koalaman/shellcheck) - static analysis for shell scripts
- [keychain](https://www.funtoo.org/Funtoo:Keychain) - keeps your SSH keys unlocked across terminal logins
- [rsync](https://rsync.samba.org/) - fast incremental file copy and sync, locally or over SSH

## System monitoring

- [htop](https://htop.dev/) (aliased as `top`) and [bottom](https://github.com/ClementTsang/bottom) (`btm`) - process and resource monitors
- [gdu](https://github.com/dundee/gdu) - disk usage analyzer

## AI coding agents

- [opencode](https://github.com/anomalyco/opencode) - terminal-based AI coding agent (v2; v1 can be pinned)
- [ccmux](https://github.com/epilande/ccmux) - run and track AI coding agents in tmux (live session states, sidebar, desktop notifications)
- [wsl-notify-send](https://github.com/stuartleeks/wsl-notify-send) - bridges desktop notifications from WSL to Windows toasts (used by ccmux)

## Python tooling

- [uv](https://github.com/astral-sh/uv) - fast Python package and project manager
- [tmuxp](https://github.com/tmux-python/tmuxp) - tmux session manager, see [Tmux usage](../../usage/30-tmux.md#manage-sessions)

The complete list, with tag and exclude names, is in the [software role](../roles/10-software.md). Usage examples are in [Data and system tools](../../usage/70-tools.md) and [AI agents](../../usage/80-ai.md).
