# AI agents

Proveasio installs [opencode](https://opencode.ai), a terminal AI coding agent, and wires it into the shell, tmux, lazygit and Neovim.

## opencode

Uses: [opencode](https://github.com/anomalyco/opencode)

Start it in a project directory:

```shell
cd ~/projects/myproject
opencode
```

On the first start, connect a model provider with `/connect` (for example GitHub Copilot, Anthropic or OpenAI). Then type what you want done. Useful commands inside opencode:

- `/models` - choose the model
- <kbd>Shift</kbd>+<kbd>Tab</kbd> or `/agents` - switch between agents, for example the build agent (makes changes) and the plan agent (read-only)
- `@` - attach a file to the prompt
- `/new`, `/sessions` - start a new session, or pick one of this directory
- `/undo`, `/redo` - revert or restore the last change
- <kbd>Ctrl</kbd>+<kbd>p</kbd> - command palette with every action; type `/` to list the slash commands

`latest` installs opencode v2. To stay on v1, see [opencode v1 and v2](../main/customization/20-versions.md#opencode-v1-and-v2).

### Find old sessions with `ocs`

opencode lists only the sessions of the current directory. `ocs` searches the sessions of **all** directories and reopens the one you pick, see [Browse opencode sessions with ocs](./20-terminal.md#browse-opencode-sessions-with-ocs).

## Track agents in tmux with ccmux

[ccmux](https://github.com/epilande/ccmux) shows which agents in your tmux panes are working, idle or waiting for you, and notifies you when one needs input. `<C-b><C-p>` (or <kbd>Alt</kbd>+<kbd>p</kbd>) opens its picker. See [Track AI coding agents (ccmux)](./30-tmux.md#track-ai-coding-agents-ccmux).

## AI commits in lazygit

In lazygit, <kbd>Ctrl</kbd>+<kbd>a</kbd> writes a commit message for the staged changes, and <kbd>Alt</kbd>+<kbd>s</kbd> splits the changes into several commits. See [AI commits in lazygit](./20-terminal.md#ai-commits-in-lazygit).

## AI in Neovim

The default Neovim config has three AI integrations. All of them need a provider login: opencode its own, CodeCompanion and Copilot a GitHub Copilot subscription (run `:Copilot auth` once).

### opencode.nvim

Uses: [opencode.nvim](https://github.com/NickvanDyke/opencode.nvim)

opencode runs in a tmux pane next to Neovim (outside tmux, in a Neovim terminal), so ccmux tracks it like any other agent. Neovim sends it prompts with context from the editor.

| Keys | Action |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>.</kbd>, `<Space>Ot` | Show or hide the opencode pane (starts opencode if needed) |
| `<Space>ON` | Open another opencode pane for this project |
| `<Space>OS` | Browse the sessions of all directories (`ocs`) in a floating window and open the one you pick in a new opencode pane |
| `<Space>Oa` | Ask about the code under the cursor (in visual mode: the selection) |
| `<Space>Oe` | Explain the code under the cursor |
| `<Space>O+` | Start a prompt with the current buffer (in visual mode: the selection) as context |
| `<Space>Os` | Pick a predefined prompt (review, fix diagnostics, document, ...) |

The prompts go to the most recent opencode session of Neovim's working directory. opencode asks for permissions in its own pane.

### CodeCompanion

Uses: [CodeCompanion](https://github.com/olimorris/codecompanion.nvim)

A chat and inline assistant inside Neovim, using GitHub Copilot models.

| Keys | Action |
|---|---|
| `<Space>Ac` | Toggle the chat buffer |
| `<Space>Aa` | (visual) Add the selection to the chat |
| `<Space>Aq` | Inline assistant: describe a change to the buffer or selection |
| `<Space>Ap` | Action palette |

### Copilot completions

Uses: [copilot.lua](https://github.com/zbirenbaum/copilot.lua), [blink-copilot](https://github.com/fang2hou/blink-copilot)

Copilot suggestions appear in the normal completion menu, next to the language server's.
